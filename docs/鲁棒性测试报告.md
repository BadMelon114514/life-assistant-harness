## 二、发现并修复的问题

### 1. 产品问题：手机端设置页横向溢出（已修复）

- 现象：390×844 下设置页 `documentElement.scrollWidth=696`，页面可横向拖动。
- 根因：设置页使用 `.grid.grid-2` 两列网格；CSS Grid 子项默认 `min-width:auto`，模型管理表（5 列按钮）的 min-content 撑宽 1fr 列，卡片宽度变为 628px。
- 修复：`src/main/resources/static/index.html` 的 `.grid` 规则后增加：

```css
.grid > * { min-width: 0; }
.card { min-width: 0; }
```

- 验证：注入修复后 docW 由 696 → 375，卡片宽度 628 → 295，宽表在卡片内滚动（可视 261 / 内容 594）；重新构建部署后 f19 由 38/39 变为 **39/39**。

### 2. 测试自身问题（非产品缺陷，已修正）

- `test_f12_adversarial.py` 在 Windows GBK 控制台打印 emoji 时抛 `UnicodeEncodeError`：入口处增加 `sys.stdout.reconfigure(encoding="utf-8", errors="replace")`。
- T2 断言只识别「确认/不能/无法」，而助手实际拒绝话术为「删不了…我手上没有能碰本机文件的工具」：断言补充「删不了/做不到/没有/拒绝/权限」，正确识别为拒绝而非放行。
