# 项目文件结构文档（含功能注释）

> 本文档对应**生活助理 Harness**（Spring Boot 3.5.6 + MyBatis + MySQL + 原生前端）当前代码库，逐文件说明结构与职责，供开发与维护参考。

## 一、项目概览

| 项 | 说明 |
|------|------|
| 后端 | Spring Boot 3.5.6（Java 17）+ MyBatis + MySQL 8.0（Druid 连接池）+ WebSocket + SSE 流式 |
| 前端 | 原生 HTML/CSS/JS 单页应用（index.html + app.js），由 Spring Boot 直接托管 |
| 客户端 | 网页端 + 安卓（Kotlin + Jetpack Compose，android/）+ iOS（SwiftUI，ios/），移动端复用同一套 REST / SSE / WebSocket |
| AI | DeepSeek（deepseek-v4-flash，OpenAI 兼容接口），支持多模型切换、指数退避重试与备用模型 |
| 数据 | MySQL（业务数据）+ 运行目录 ./data（知识库/任务/记忆文件） |
| 架构理念 | Agent 环架（Harness）：所有功能（工具、权限、计划、记忆、任务、多 Agent、知识库、MCP/Skill）挂在同一 Agent 循环（ToolScheduler）周围 |

## 三、后端源码结构（src/main/java/com/badmelon/farming）

### 3.1 启动与配置层（config/）

| 文件 | 功能注释 |
|------|---------|
| FarmingApplication.java | 启动类；@SpringBootApplication + @EnableScheduling（开启定时任务：Teammate 轮询、提醒触发） |
| config/StartupInitializer.java | 启动初始化：调用 TeammateService 创建默认 3 个 Teammate 工作进程（运营分析/客服响应/商品助理），失败仅告警不阻塞启动 |
| config/WebSocketConfig.java | WebSocket 注册：将 MonitorWsHandler 挂到 /ws/monitor（前端监控/通知通道） |
| config/MonitorWsHandler.java | WebSocket 处理器：维护在线 session 集合，broadcast(json) 广播消息；前端借此接收监控快照与 assistant_notify 提醒推送 |

### 3.2 控制器层（controller/）——REST API 入口

| 文件 | 功能注释 |
|------|---------|
| AssistantController.java | 助手核心接口：POST /chat、/chat-stream（SSE 流式：token/summary/skill_draft/mcp_draft/confirm/done 事件）、/stop（中断流式）、/confirm（高危操作确认执行）；**POST/GET /schedule + DELETE /schedule/{id}（定时提醒管理，本轮新增）**；**GET /location（本机时间+定位，本轮新增）** |
| AiModelController.java | AI 模型管理：列表、新增、编辑、激活切换、删除 |
| ChatHistoryController.java | 聊天记录：GET/POST/DELETE /api/chat/history（按会话）、会话列表、新建/删除子会话 |
| ClawHubController.java | ClawHub 技能市场检索（https://clawhub.ai），供聊天助手自动安装技能时使用 |
| ExtensionController.java | 开发者扩展端口 /api/extensions：能力清单（CLI 白名单、内置库资源、内置工具、工具策略）与 cli-allowlist 扩展 |
| KnowledgeController.java | 知识库：上传（txt/pdf/docx/xlsx/pptx/csv，自动解析）、列表、查看全文、删除 |
| McpController.java | MCP 服务管理：CRUD、toggle 启停、/{id}/test 连通性测试（http 类型 GET 200 自动激活）、URL 下载导入、安全扫描、内置库一键导入、草稿导入 |
| MemoryController.java | 记忆库：列表、新增/记住、删除 |

| SearchController.java | 联网搜索：开关状态查询/切换（bing / duckduckgo） |
| SettingsController.java | 系统设置：读取（密钥打码）、保存、AI 服务连通性测试 |
| SystemController.java | 前端关闭后端：POST /api/system/shutdown（本机 + X-Shutdown-Confirm 头校验 → WS 广播 server_shutdown → 延迟优雅停机并联动关闭 context-store:8765） |
| SkillController.java | Skill 技能管理：CRUD、启停、URL 下载导入、安全扫描、内置库一键导入、草稿导入 |
| TaskController.java | 任务看板：创建（含依赖）、列表、认领/完成/删除 |

### 3.5 服务层（service/）——核心业务逻辑

## 八、一次对话的端到端数据流（理解架构的关键）

```
用户在生活助理输入消息
  → 前端 sendChat：保存用户消息，创建流式气泡
  → POST /api/assistant/chat-stream（SSE）
  → AssistantService.streamChat：
     1) 能力决策（SkillMcpGeneratorService：是否需要新增 Skill/MCP）
     2) 上下文组装（团队/任务/记忆/启用技能/知识库检索/联网搜索）
     3) ToolScheduler.runAgentLoop：多轮工具调度
        ├─ 内置工具（时间/天气/热点/数据分析/文件/CLI/媒体…）
        ├─ MCP 工具（http/sse：reminder 提醒、local-geo 定位、context-store 上下文…、外部服务）
        └─ 多 Agent 调度（dispatch_teammates → 任务看板 → Teammate 执行）
     4) AI 流式生成回复（含 [[SCHEDULE:]] 提醒标记、图表容器、一键导入草稿）
     5) 自验证自纠错（答非所问自动改写）
  → 前端流式渲染 Markdown/图表；解析 SCHEDULE 标记调 /api/assistant/schedule 入队
  → 定时提醒到期：ScheduledTaskService 写历史 + WebSocket 推送 → 前端 ⏰ 气泡
```
