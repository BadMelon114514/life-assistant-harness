## 一、快速开始

### 第 1 步：启动系统（电脑端）

双击桌面上的 **「生活助理 Harness」** 图标（或运行 `dist\生活助理Harness一键启动.exe`）。

启动器会依次启动：

| 服务 | 端口 | 作用 |
|------|------|------|
| 主程序（Spring Boot） | 8080 | 网页、接口、WebSocket |
| 上下文存储（Python） | 8765 | 分级上下文、快照、文档摘要 |

启动完成后会自动打开浏览器；若没有自动打开，手动访问 **http://127.0.0.1:8080**。

> 首次启动需要几秒到十几秒，请等待浏览器出现页面；黑色命令行窗口是服务进程，**使用期间不要关闭**。

### 第 2 步：配置 AI（首次使用）

1. 左侧点击 **设置**；
2. 在「AI 服务」中填入你的 **API Key**（DeepSeek 等，OpenAI 兼容接口）；
3. 点击 **保存**，状态变为「已配置」即可。

> 已经有可用模型时这一步可跳过；也可以在「模型管理」里配置多个模型并切换。

### 第 3 步：开始对话

左侧点击 **生活助理**，在输入框里直接提问，按 Enter 或点「发送」。

例如：

- 「帮我把这周的任务整理成清单」
- 「根据知识库里的产品报告，总结三个卖点」
- 「10 分钟后提醒我喝水」
- 「现在几点了？我在哪个城市？」

## 三、生活助理：AI 对话

### 3.1 基本操作

| 操作 | 说明 |
|------|------|
| 发送 | 输入后按 Enter，或点「发送」 |
| 停止 | 生成过程中按钮变为「停止」，点击可中断，已生成内容保留 |
| 子对话 | 顶部「子对话」下拉可切换、新建、删除对话窗口 |
| 清空/回滚 | 清空当前对话记录，回到初始欢迎界面（不可恢复） |
| 历史 | 对话自动保存；切换页面、刷新浏览器后都会恢复 |

### 3.2 助手能做什么

- **问答与写作**：生活常识、办公文案、总结、翻译、计划；
- **读知识库**：提到文档名或问「知识库里关于 X 的内容」，助手会检索并阅读原文；
- **用记忆**：记住你的偏好与长期信息，在后续对话中自动带上；
- **查任务/团队**：查看任务进度、成员状态；
- **联网搜索**：开启后检索最新信息（设置里可开关）；
- **时间与定位**：回答当前时间、日期、所在城市；
- **定时提醒**：见 3.4；
- **生成图表**：例如「把下面的数据画成柱状图」；
- **文件操作**：读写项目内文件（会弹出确认，见 3.3）；
- **自动扩展**：识别到需要新技能/MCP 时生成草稿，供你一键导入（见 3.5）。

### 3.3 高危操作确认

当助手要执行以下操作时，会先弹出确认框，显示操作类型、路径和内容预览：

- 写入/覆盖文件
- 删除文件或目录
- 执行项目内脚本
- 创建目录

**只有点「确认执行」才会真正执行**；点取消则放弃。请仔细核对路径后再确认。

### 3.4 定时提醒

直接用自然语言说，例如：

- 「10 分钟后提醒我喝水」
- 「1 小时后提醒我起身活动」（用「X 分钟后 / X 小时后」最稳；绝对时间由助手换算）
- 「30 分钟后提醒我看邮件，标题写『看邮件』」

到点后页面顶部会弹出提醒横幅，同时提醒内容会写入当前对话历史。
也可以让助手「查看我的定时提醒」「取消第 3 条提醒」。

> 提醒依赖后端运行；电脑关机或后端关闭期间不会触发。

### 3.5 技能 / MCP 草稿

当你说「帮我做一个周报技能」「下载一个小红书账号诊断的技能」时，助手可能生成草稿并弹出卡片：

- 卡片显示名称、描述和安全扫描结果；
- 点「一键导入」加入系统，点「忽略」放弃；
- 导入后到「Skill 技能」或「MCP 服务」页面可看到并启用。

### 3.6 记忆

- 说「记住：我喜欢喝拿铁」→ 写入记忆库；
- 密码、银行卡号等敏感信息会被拒绝保存；
- 到「记忆库」页面可以查看、补充、删除。

### 3.7 提问小技巧

- 说清楚对象和范围，例如「根据《202608 消费电子报告》总结」；
- 可以连续追问，助手会带上历史上下文；
- 需要最新信息时打开「联网搜索」；
- 回答不满意可以直接说「重写，更简短一点」。

## 四、进程监控

用于查看后台 Teammate 的工作状态，每 5 秒自动刷新，WebSocket 有变化时即时更新。

- **汇总卡片**：成员总数、工作中、空闲、平均进度；
- **成员卡片**：名称、角色、状态、当前任务、进度条、心跳时间；
- **最近日志**：最近 40 条运行日志，ERROR/WARN 会标色；
- **停止进程**：成员卡片上的「停止」按钮（二次确认），停止后该成员不再认领任务。

默认成员：运营分析、客服响应、商品助理。

---

## 五、任务看板

- **筛选**：全部 / 待处理 / 进行中 / 已完成；
- **新建任务**：点页面上方的「＋ 新建任务」（手机端为右下角「＋」），填标题、描述、可选的依赖任务；
- **认领**：待处理任务点「认领」，负责人变为当前使用者；
- **推进**：进行中任务点「+10%」，或直接「完成」；
- **删除**：卡片上的删除按钮（二次确认）。

开启「自动认领」后，空闲成员会自动领取待处理任务（见设置 → 系统参数）。

## 六、本地知识库

### 6.1 上传文档

1. 进入「本地知识库」；
2. 点击上传区或把文件拖进去；
3. 系统自动解析文本，并生成摘要。

支持：TXT、Markdown、PDF、Word（docx）、Excel（xlsx）、PPT（pptx）等常见文档。

### 6.2 使用文档

- **搜索**：顶部搜索框按关键词检索；
- **查看**：点卡片查看摘要与正文；
- **让助手读**：在对话里说「根据《文件名》…」或「知识库里关于…的内容」；
- **删除**：详情页或卡片上的删除按钮。

> 单个文件过大或格式不支持时会提示失败；扫描版 PDF（纯图片）可能无法提取文字。

## 七、记忆库

- 展示所有长期记忆：内容、分类、重要度、更新时间；
- 「＋」可手动新增记忆（内容、分类、重要度 1-10）；
- 删除不再需要的记忆；
- 对话时助手会自动带上相关记忆，无需重复交代。

## 八、MCP 服务

MCP（Model Context Protocol）用于给助手接入外部工具或数据，例如搜索、地图、数据库、提醒服务等。

| 操作 | 说明 |
|------|------|
| 启用/停用 | 控制该服务是否参与工具调度 |
| 测试 | 检查地址/命令是否连通，返回 ✅/❌ |
| 新增 | 填名称、类型（http / sse / stdio）、地址或命令、描述 |
| 删除 | 移除服务（二次确认） |
| 远程导入 | 输入 URL 或从 ClawHub 下载，自动做安全扫描后导入 |

常见问题：

- http 服务测试失败：检查地址、端口、服务是否启动；
- stdio 服务：确认本机命令存在、路径正确；
- 导入被拦截：安全扫描发现可疑命令（如反弹 shell、凭据读取），请勿放行来源不明的服务。

## 九、Skill 技能

技能是一段可复用的指令，启用后会注入到对话中，让助手按固定套路做事。

- **查看**：点卡片看完整指令内容；
- **启用/停用**：开关即时生效；
- **新增**：填名称、分类、描述、指令内容；
- **下载导入**：输入 URL 或从 ClawHub 获取，导入前自动安全扫描。

示例技能：周报生成、会议纪要、竞品分析、SQL 助手、客服话术等。

### 关闭与重启

- 关闭：设置页「关闭后端服务」，或侧栏底部电源按钮；
- 关闭后前端显示「服务已关闭」离线页，手机端也会显示离线页；
- 重启：重新双击桌面「生活助理 Harness」快捷方式。

> 关闭不会删除任何数据；重启后对话、任务、知识库都还在。

## 十一、手机端使用（安卓）

安卓客户端是**瘦客户端**：只负责界面与交互，数据仍在电脑端。使用前请确保电脑端已启动，且手机与电脑在同一 Wi-Fi。

### 11.1 安装

1. 把 `dist\生活助理Android.apk` 传到手机（微信文件传输、数据线、网盘均可）；
2. 点击安装；首次安装需允许「安装未知来源应用」；
3. 要求 Android 8.0 及以上，安装包约 10 MB。

### 11.2 连接电脑

1. 在电脑上查局域网 IP：命令行执行 `ipconfig`，找到「IPv4 地址」，例如 `192.168.1.10`；
2. 手机打开 App → 底部「更多」→「设置」→「服务器地址」；
3. 填入 `http://192.168.1.10:8080`（把 IP 换成你自己的），点「保存并测试」；
4. 看到「连接成功」即可。

> 用安卓模拟器时无需改地址，默认 `http://10.0.2.2:8080` 指向电脑本机。

**连不上时依次检查**：

- 电脑端是否在运行（浏览器能打开 127.0.0.1:8080）；
- 手机和电脑是否同一 Wi-Fi（不要一个连 5G、一个连访客网络）；
- Windows 防火墙是否放行 8080（首次启动时选择「允许访问」）；
- IP 是否填对（重新 `ipconfig` 确认，路由器重启后 IP 可能变化）。

### 11.3 功能对照

| 功能 | 手机端 | 说明 |
|------|:---:|------|
| 对话（流式、历史、停止） | ✅ | 与网页一致 |
| 定时提醒 | ✅ | 应用在前台时弹出提示 |
| 进程监控 | ✅ | 5 秒刷新 + 实时推送 |
| 任务看板 | ✅ | 筛选、认领、推进、完成、新建 |
| 知识库 | ⚠️ | 可检索/查看/删除/新增文本，**不支持上传文件** |
| 记忆库 | ✅ | 查看、新增、删除 |
| MCP / 技能 | ✅ | 启用停用、测试、新增、删除 |
| 设置 | ✅ | 服务器地址、API Key、主题、关闭后端 |
| 模型管理 / 子对话管理 | ❌ | 仍在电脑网页端操作 |

### 11.4 手机端注意事项

- 应用退到后台后 WebSocket 会断开，**收不到定时提醒**，回到前台会自动重连；
- 主题（跟随系统/浅色/深色）保存在手机本地；
- 卸载 App 不会影响电脑端数据；
- 点击「关闭后端服务」会关闭电脑上的服务，所有客户端都会离线。

## 十三、数据、备份与安全

### 13.1 数据在哪里

| 数据 | 位置 |
|------|------|
| 对话、任务、知识库、记忆、MCP、技能 | MySQL 数据库 `farming_harness` |
| 上传原文件、任务文件 | 项目目录 `data/` |
| 运行日志 | 项目目录 `logs/` |

### 13.2 备份与迁移

1. 关闭后端；
2. 备份数据库：`mysqldump -uroot -p farming_harness > backup.sql`（命令不存在时用 MySQL 安装目录 `bin` 下的 mysqldump.exe）；
3. 备份 `data/` 目录；
4. 换机时先建库、导入 `backup.sql`，再把 `data/` 放回原位。

### 13.3 安全提示

- 系统**没有登录鉴权**，默认给本机/局域网使用，**不要映射到公网**；
- API Key 保存在电脑端数据库；设置页与列表以掩码显示，模型管理界面可能回显完整 Key，注意不要截图外传；
- 不要在公共 Wi-Fi 下开放 8080 端口；
- 助手执行文件写入/删除前会二次确认，确认前请核对路径；
- 从网络导入的 MCP/技能会做安全扫描，但来源不明的仍不建议启用。

## 十四、常见问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 浏览器打不开 127.0.0.1:8080 | 后端未启动 / 端口被占用 | 重新双击启动器；查看 `logs/launcher.log`、`logs/app_exe.log` |
| 页面显示「服务已关闭」 | 后端被关闭 | 重新启动桌面快捷方式 |
| 提示未配置 API Key / 调用失败 | Key 未填、失效、余额不足 | 设置页重新填写；检查网络 |
| 回复很慢或中断 | 网络波动、模型限流 | 稍后重试；点「停止」后重新提问 |
| 定时提醒没响 | 后端关闭 / 时间已过 / 手机端在后台 | 保持后端运行；手机端提醒需应用在前台 |
| 上传文档失败 | 格式不支持、文件过大、扫描版 PDF | 换格式或拆分文件 |
| 知识库搜不到 | 文档未解析成功 | 查看文档解析状态，重新上传 |
| 任务无法认领 | 任务已完成或被他人认领 | 刷新页面查看最新状态 |
| 手机连不上 | IP 错、不同网段、防火墙拦截 | 按 11.2 逐项检查 |
| 页面样式错乱 | 浏览器缓存旧版本 | Ctrl+F5 强制刷新 |
| 助手说「无法获取时间/位置」 | 定位服务不可用 | 检查网络；内置 local-geo MCP 是否启用 |
| 关闭后数据丢失？ | 不会 | 数据在数据库与 data 目录，重启即恢复 |

更多运维问题（端口、数据库、日志、二次开发）见 [操作指南.md](操作指南.md) 第十四章。
